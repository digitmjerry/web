HP Color LaserJet Pro M154nw MacBook 設定指南

當 MacBook 無法在網路中找到印表機時，通常是因為印表機尚未成功連線至 Wi-Fi 網路。請依照以下完整步驟進行設定。

第一步：重設印表機網路設定

此步驟可清除舊的錯誤連線資訊，讓印表機重新進入配對狀態：

  1. 確保印表機電源已開啟。
  2. 同時按住印表機控制面板上的「無線」按鈕（藍色 Wi-Fi 圖示）與「取消」按鈕（❌ 圖示）。
  3. 持續按住約 5 秒鐘，直到電源指示燈與無線指示燈開始閃爍後放開。
  4. 靜待約 1 分鐘，當藍色無線燈呈現緩慢閃爍狀態時，即代表已成功進入配對模式。

第二步：將印表機連上 Wi-Fi（二選一）

方法 A：使用 WPS 按鈕（最快速，免輸入密碼）

  1. 確認印表機的藍色無線燈目前正處於閃爍狀態。
  2. 按下家中的 Wi-Fi 分享器（路由器）上的 WPS 按鈕（部分機型需按住 3 秒）。
  3. 在 2 分鐘內回到印表機旁，按住「無線」按鈕 3～5 秒 啟動配對。
  4. 當印表機的藍色無線燈停止閃爍並保持常亮時，即表示連線成功。

方法 B：使用 USB 傳輸線輔助設定

  1. 若分享器無 WPS 按鈕，請使用 USB 傳輸線 直接連接 MacBook 與印表機。
  2. 開啟 Mac 瀏覽器，前往 123.hp.com 下載並安裝 HP Smart App。
  3. 開啟 App 並點擊「新增印表機」，系統將透過 USB 偵測到印表機。
  4. 依照畫面引導輸入家中的 Wi-Fi 密碼，協助印表機完成網路連線。
  5. 連線成功後，即可將 USB 傳輸線拔除。

第三步：在 Mac 系統中新增印表機

當印表機的藍色 Wi-Fi 燈常亮後，請確認 MacBook 已連線至相同的 Wi-Fi 網路名稱：

  1. 點擊 Mac 畫面左上角的 蘋果標誌 ()。
  2. 進入 「系統設定」（舊版系統為「系統偏好設定」）。
  3. 於左側選單滑動並點選 「印表機與掃描器」。
  4. 點擊 「加入印表機、掃描器或傳真機...」 按鈕。
  5. 在清單中選取 HP Color LaserJet Pro M154nw，確認使用 AirPrint 後點擊 「加入」 即可完成。
💡 注意事項：
  • 本印表機僅支援 2.4GHz 頻段的 Wi-Fi 網路，不支援 5GHz。設定時請確保 Mac 連接至 2.4GHz 的網路名稱。
  • 若後續需要進階管理或檢視碳粉匣狀態，可至 HP 官方驅動程式頁面 下載專屬工具。
